Distance Metrics
=================


There exist several coordinate representations for the two-dimensional hyperbolic space. In this package we focus on the two most common ones, the Poincaré disk coordinates and the Weierstraß (or hyperboloid) coordinates. More details can be found in the `release publication <https://arxiv.org/abs/2309.10844>`__.
