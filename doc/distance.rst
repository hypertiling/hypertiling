Distance Metrics
=================


There are several coordinate representations available for the two-dimensional hyperbolic space, in general. In this package we focus on the two most common ones, the Poincare disk coordinates and the Weierstrass (or hyperboloid) coordinates. More details can be found in the `release publication <https://arxiv.org/abs/2309.10844>`__.
